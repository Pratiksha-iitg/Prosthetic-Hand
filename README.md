# From Signal to Motion: Building a Flex Sensor Controlled Robotic Hand 🤖🖐️

## Project Overview

A prototype robotic hand controlled using **flex sensors and Arduino**. The flex sensor detects bending, and the sensor output is used to control the movement of the corresponding finger.

- Jumper Wires

## How It Works

The flex sensor changes its resistance when bent. The Arduino reads this change and uses the sensor input to control the servo motor, resulting in the movement of the robotic finger.

**Flex Sensor → Arduino → Servo Motor → Finger Movement**
